# Новый сайт InView: принятые решения (2026-11-16)
Ростик ответил только «делай в отдельной папке, ок»; остальное я взял по умолчанию, ждёт подтверждения:
- Один сайт: InView — основа, WzrokOK — раздел «Sklep».
- Без корзины: карточки с ценами, кнопка ведёт в магазин wzrokok.pl.
- Продукты из брифа без описаний (IontoRetina, FLiGHT, fixOflex, Goniowash, Nexa Vision, NuLids, AsekOfta, Kaleidos, PRO·PIO) — кнопка «Odkryj» ведёт на форму контакта с темой.
- Таймер «JUTRO» не показываю, нет даты — стоит «Wkrótce».
- Только польский язык.
- Статика: `python3 build.py` собирает все страницы из `data/source.json`.
- PDF-материалы пока ссылаются на старый inviewmedical.pl — при отключении старого сайта их надо перенести.

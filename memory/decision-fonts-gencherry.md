# Шрифт «как на gencherry.com»
- На gencherry.com стоят фирменные шрифты GCH Sans и GCH Mono («Генерал Черешня»). Их нет в свободном доступе — копировать на чужой сайт нельзя.
- Для сайта Starlink Mini (2026-11-12) по просьбе Ростика весь текст на Tektur (замена GCH Mono; Onest убрали) (подписи, метки, цены, цифры). Tektur выбрал по скрину Ростика «ГЕНЕРАЛ ЧЕРЕШНЯ BULLET» — самый похожий из бесплатных с кириллицей. Меняется в одном месте — ссылка Google Fonts и переменные --font-sans / --font-mono.
- Сайт gencherry блокирует автоматический браузер и скачивание CSS — стили кнопок напрямую снять не вышло.

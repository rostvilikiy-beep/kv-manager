# Клиент: оптимизация ПК (Telegram MiniApp), ноябрь 2026
- Имя клиента пока неизвестно. Делает оптимизацию ПК/ноутбуков, фишка — личный бренд (стример на Twitch, CS2).
- ТЗ от 2026-11-20 (на украинском): MiniApp с нижними вкладками, как у UltraCom.
- Вкладки: 1) Головна — видео, соцсети, плашка «стрим на Twitch», достижения, кнопка «Підібрати оптимізацію» → квиз из 5 вопросов → лучшие отзывы по его железу + пакет → «Обрати пакет»;
  2) Пакети+Записи — пакеты, кнопка «Замовити і обрати час»: свободный слот или переписка с готовым шаблоном;
  3) До/Після, Відгуки — все отзывы, поиск по процессору/видеокарте;
  4) FAQ + кнопка «Допомога» → чат с экспертом;
  5) Особистий кабінет — железо клиента (из квиза/отзывов), его заказы.
- Цифры в ТЗ («3000 ELO CS2», «400+ ПК», «+30% FPS») клиент дал как пример («по типу») — перед использованием уточнить.

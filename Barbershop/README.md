# Barbershop — Brzytwa

Demo strony barbershopu po polsku z elementami 3D (Three.js): obracający się słupek barberski, otwierająca się brzytwa, cennik, zespół i rezerwacja online.

Jeden plik `index.html`, bez budowania. Otwórz go w przeglądarce albo wrzuć na dowolny hosting statyczny (Vercel, Netlify, GitHub Pages).

Dane salonu (nazwa, adres, telefon, ceny, opinie) są przykładowe. Formularz rezerwacji działa w trybie demo i nigdzie nie wysyła zgłoszeń.

# 🎯 Lead Bot — заказы и вакансии из Telegram-чатов и Threads

Бот читает Telegram-группы и Threads. Когда кто-то пишет, что ему нужен исполнитель
(сайт, бот, дизайн, логотип, SMM, монтаж…), бот присылает карточку:

```
🤖 Ищут разработчика телеграм-бота

Нужно сделать телеграм-бота с широким спектром функций. Формат работы не указан.

Опубликовано: 11.11.2026 10:04
Источник: Threads
Сфера: Чат-боты

На бесплатном тарифе заказы приходят на 4 ч позже — …
[ [1/5] Открыть контакты 🔑 ]
[ Открыть заказ 🔍 ]
[ ⭐ Сохранить ] [ ✍️ Отклик ]
[ Обновить сферы 🔄 ]
```

## Возможности

**Карточка заказа**
- ИИ пишет заголовок («Ищут …»), выжимку, требуемый опыт, бюджет и срок.
- Контакты в тексте скрыты 🔒. Кнопка «Открыть контакты» показывает автора, телефоны,
  @username, почту и оригинал. На бесплатном тарифе — лимит в сутки.
- «⭐ Сохранить», «✍️ Отклик» (ИИ пишет черновик ответа заказчику от твоего имени),
  «Обновить сферы».

**Тарифы**
- Бесплатный: заказы приходят с задержкой (`FREE_DELAY_HOURS`, по умолчанию 4 ч),
  контакты — `FREE_CONTACTS_PER_DAY` раз в сутки, до 2 своих групп.
- Pro: заказы мгновенно, контакты без лимита, ИИ-отклики, до 20 своих групп.
  Оплата **Telegram Stars** прямо в боте — без ИП и платёжного провайдера.
- Рефералы: за каждого приглашённого — `REF_BONUS_DAYS` дней Pro.

**Настройки поиска**
- 🔍 Сферы (14 категорий: сайты, лендинги, магазины, чат-боты, приложения, UI/UX,
  логотип и брендинг, SEO, реклама, SMM, видео, тексты, автоматизация, AI).
- 📡 Источники: Telegram-чаты / Threads.
- 🌍 Язык заказов: украинский / русский / английский.
- 💼 Заказы или вакансии: разовые заказы / работа в компании.
- 🏠 Формат работы: онлайн / офлайн / гибрид.
- 🖼 Оформление: кратко (выжимка ИИ) или полный текст.
- ➕ Свои группы: чаты, которые бот мониторит персонально для тебя.
- 🔑 Свои ключевые слова и 🚫 чёрный список.
- ✍️ «О себе» — для генерации откликов.

**Ещё**: 📰 лента за 7 дней, ⭐ сохранённые, 👤 профиль со статистикой, пауза,
антидубли (один запрос из 10 чатов придёт один раз).

**Админка**: `/join @chat` — общий чат для всех, `/leave`, `/chats`, запросы Threads `/tq_add`,
`/users`, `/grant <id> <дней>` — выдать Pro вручную.

## Как это устроено

```
[юзербот в TG-чатах] ─┐
                      ├─> фильтр по словам ─> антидубли ─> ИИ ─> очередь (Pro сразу, free +4ч) ─> карточка
[Threads API поиск] ──┘
```

- **Юзербот** — это обычный Telegram-аккаунт под управлением скрипта (Telethon). Он состоит в
  чатах и читает новые сообщения. Обычный бот так не может: в чужие чаты его не добавят.
- **Бот** (aiogram) — это интерфейс: меню настроек и карточки заказов.

## Установка

### 1. Что нужно получить

| Что | Где |
|---|---|
| `BOT_TOKEN` | [@BotFather](https://t.me/BotFather) → `/newbot` |
| `ADMIN_IDS` | твой ID: [@userinfobot](https://t.me/userinfobot) |
| `TG_API_ID`, `TG_API_HASH` | https://my.telegram.org → API development tools (войти **с аккаунта юзербота**) |
| `ANTHROPIC_API_KEY` (необязательно) | https://console.anthropic.com → API Keys |
| `THREADS_ACCESS_TOKEN` (необязательно) | Meta for Developers, приложение с Threads API и правом `threads_keyword_search` |

> ⚠️ Для юзербота **заведи отдельный аккаунт** (вторая сим-карта / виртуальный номер), не основной.
> При слишком частых вступлениях в чаты Telegram может ограничить аккаунт.

### 2. Запуск

```bash
cd lead-bot
cp .env.example .env        # заполни значения
pip install -r requirements.txt
python login.py             # один раз: номер телефона + код из Telegram
python main.py
```

Или в Docker (на VPS):

```bash
cp .env.example .env
docker compose run --rm leadbot python login.py   # один раз авторизовать юзербот
docker compose up -d
```

### 3. Настройка

1. Открой своего бота → `/start`. Появится меню.
2. **👑 Админка** → добавляй чаты: `/join @freelance_chat` (или ссылку-приглашение `https://t.me/+...`).
   Юзербот слушает **все** группы, в которых состоит, поэтому можно вступать и вручную с телефона.
3. **🔍 Что искать** — отметь нужные категории.
4. При желании добавь свои ключевые и стоп-слова.

## Про Threads

Используется официальный Threads API (`keyword_search`). Нюансы:
- нужно создать приложение в Meta for Developers и получить long-lived токен;
- пока приложение не прошло App Review на `threads_keyword_search`, поиск может возвращать
  только посты тестировщиков приложения;
- на поиск есть лимит запросов, поэтому бот опрашивает Threads раз в `THREADS_POLL_MINUTES`
  минут по списку запросов (`/tq`).

## Про ИИ-фильтр

Каждое сообщение сначала проходит бесплатный фильтр по словам. Только подошедшие
(обычно единицы процентов от всего потока) отправляются в Claude — один запрос на сообщение,
даже если пользователей много. Модель задаётся в `CLAUDE_MODEL`; по умолчанию
`claude-opus-5-5`, для заметной экономии можно поставить `claude-haiku-5-5`.
Если ИИ недоступен (нет ключа, ошибка сети), решает обычный фильтр.

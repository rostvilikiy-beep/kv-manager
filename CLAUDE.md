# Инструкции для Claude

## Создание сайта, страницы или проекта

Когда пользователь просит сделать сайт, страницу, интерфейс или новый проект, всегда используй три скилла:

1. `shadcn` — для компонентов интерфейса (кнопки, формы, диалоги и т.д.).
2. `emil-design-eng` — для аккуратного вида, анимаций и мелких деталей.
3. `web-design-guidelines` — в конце проверь готовый код по правилам хорошего дизайна и доступности, исправь найденные проблемы.

Порядок: сначала делай интерфейс с `shadcn` и `emil-design-eng`, потом проверяй через `web-design-guidelines`.
